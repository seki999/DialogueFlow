# File Storage vs EFS

One-line summary: a managed NFS file storage service, supporting shared access from multiple instances.

```mermaid
flowchart TD
    F[File Storage] --> I1[Instance 1]
    F --> I2[Instance 2]
    F --> I3[Instance 3]
    I1 -.simultaneous read/write.- F
    I2 -.simultaneous read/write.- F
    I3 -.simultaneous read/write.- F
```

## Key Points
* AWS equivalent: EFS
* Based on the NFS protocol, supports multiple compute instances mounting and reading/writing simultaneously
* Typical use cases: shared application file directories across instances, media file storage for content management systems
* Difference from Block Volumes: Block Volumes is typically single-instance exclusive, while File Storage is designed for multi-instance sharing from the start
