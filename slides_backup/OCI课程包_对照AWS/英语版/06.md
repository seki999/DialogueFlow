# Billing Units Explained: OCPU vs vCPU

One-line summary: OCI bills by OCPU; 1 OCPU is roughly equal to 2 vCPUs (a full physical core's hyperthread pair).

```mermaid
flowchart LR
    A[1 physical core] --> B[Hyperthreading enabled]
    B --> C[AWS counts this as: 2 vCPU]
    B --> D[OCI counts this as: 1 OCPU]
    C -.equivalent.- D
```

## Key Points
* AWS bills by vCPU: 1 vCPU = 1 hyperthread
* OCI bills by OCPU: 1 OCPU = a full physical core's hyperthread pair ≈ 2 vCPUs
* The conversion trap: don't treat OCI's "4 OCPU" as equivalent to AWS's "4 vCPU" - it's actually closer to 8 vCPUs worth of compute
* Before comparing costs, convert both sides to physical core counts first, then compare pricing
