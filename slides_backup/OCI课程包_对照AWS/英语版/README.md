# Course Notes: 15 Commonly Used OCI Services, Compared with AWS (English Version)

## Course Topic
For learners with an AWS background, this course systematically explains 15 commonly used services on
Oracle Cloud Infrastructure (OCI), directly mapping each concept to its corresponding AWS service.

## Total Chapters
28 file pairs (01-28), 56 files total, plus this README.md.

## File Numbering Rules
- Each chapter consists of two files with the same number: `NN.md` and `NN.conversation`
- Numbers use two digits, starting at 01, continuous with no skipped numbers
- Example: `01.md` corresponds to `01.conversation`, `02.md` corresponds to `02.conversation`, and so on

## Relationship Between .md and .conversation
- `.md` files: display the chapter's knowledge structure, Mermaid diagrams, and key points - meant for the screen display during video recording
- `.conversation` files: a dialogue between `speaker 1` (the learner's perspective) and `speaker 2` (the expert's perspective),
  walking through the diagrams and points in the same-numbered `.md` file one by one
- The two files correspond strictly - every point raised in a `.conversation` file can be traced back to the same-numbered `.md`

## Recommended Playback Order
Simply play/read through numbers 01 to 28 in order. Chapters are organized with the following logic:

1. Background and core concepts (01-03)
2. Compute category: overview + 7 sub-topics (04-12)
3. Storage category: overview + 4 sub-topics (13-17)
4. Networking category: overview + 4 sub-topics (18-22)
5. Database category: overview + 2 sub-topics (23-25)
6. Security category (26)
7. Common pitfalls and Free Tier (27)
8. Summary and further reflection (28)

## Usage Suggestions
- Use each `NN.md` as visual reference for screen recording, and `NN.conversation` as an audio narration/podcast script
- All Mermaid diagrams have been confirmed compatible with GitHub Markdown rendering
- The dialogue text is plain text dialogue with no Markdown formatting, suitable for feeding directly into a speech-synthesis engine
