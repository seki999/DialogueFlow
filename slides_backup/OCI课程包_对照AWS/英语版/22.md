# FastConnect vs Direct Connect

One-line summary: connect a data center to the cloud via a dedicated line, bypassing the public internet for more stable bandwidth and latency.

```mermaid
flowchart LR
    DC[Enterprise Data Center] -- Dedicated Line --> FC[FastConnect]
    FC --> VCN[VCN]
    VCN --> Cloud[Cloud Resources]
```

## Key Points
* AWS equivalent: Direct Connect
* Use case: establishing a dedicated-line connection between an enterprise data center and a VCN in the cloud, replacing public-internet VPN
* Advantages: more stable bandwidth, lower latency, better security
* A key piece of hybrid cloud architecture, typically paired with VCN and route tables to decide which traffic goes over the dedicated line versus the public internet
