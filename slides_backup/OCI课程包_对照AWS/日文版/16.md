# File Storage vs EFS

一言で言うと:マネージドNFSファイルストレージサービス。複数インスタンスでの共有アクセスをサポート。

```mermaid
flowchart TD
    F[File Storage] --> I1[インスタンス1]
    F --> I2[インスタンス2]
    F --> I3[インスタンス3]
    I1 -.同時読み書き.- F
    I2 -.同時読み書き.- F
    I3 -.同時読み書き.- F
```

## 要点
* AWS対応:EFS
* NFSプロトコルベースで、複数のコンピュートインスタンスが同時にマウントして読み書き可能
* 典型的なシナリオ:複数インスタンスで共有するアプリケーションファイルディレクトリ、コンテンツ管理システムのメディアファイルストレージ
* Block Volumesとの違い:Block Volumesは通常単一インスタンス専有、File Storageは元々複数インスタンス共有向けに設計されている
