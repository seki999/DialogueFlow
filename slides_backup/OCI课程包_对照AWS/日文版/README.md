# 講座説明:OCI 15の主要サービス AWS対照講座(日本語版)

## 講座テーマ
AWSの基礎知識がある学習者を対象に、Oracle Cloud Infrastructure(OCI)の15の主要サービスを体系的に解説する。
各知識ポイントは対応するAWSサービスと直接対照させながら説明する。

## 総章数
28組のファイル(01〜28)、計56ファイル、加えて本README.md。

## ファイル番号の規則
- 各章は同名の2ファイル `番号.md` と `番号.conversation` で構成
- 番号は2桁の数字を使用し、01から連続で番号を振る。飛び番なし
- 例:`01.md` は `01.conversation` に対応、`02.md` は `02.conversation` に対応、以下同様

## .mdと.conversationの対応関係
- `.md` ファイル:当該章の知識構造、Mermaid図、要点を表示。動画収録時の画面表示に使用
- `.conversation` ファイル:`speaker 1`(学習者視点)と `speaker 2`(専門家視点)の対話形式で、
  同番号の `.md` ファイルの図と要点を一つずつ解説
- 両ファイルの内容は厳密に対応しており、`.conversation` に出てくるすべての知識ポイントは同番号の `.md` に出典がある

## 推奨再生順序
番号01から28まで順番に再生/読み上げればよい。章立ては以下のロジックで構成:

1. 背景と核心概念(01-03)
2. コンピュート分類:概観 + 7つの詳細トピック(04-12)
3. ストレージ分類:概観 + 4つの詳細トピック(13-17)
4. ネットワーク分類:概観 + 4つの詳細トピック(18-22)
5. データベース分類:概観 + 2つの詳細トピック(23-25)
6. セキュリティ分類(26)
7. よくある誤解と無料プラン(27)
8. まとめと発展的な考察(28)

## 使用上のアドバイス
- 各組の `番号.md` を録画画面の参考資料として、`番号.conversation` を音声読み上げ/ポッドキャスト台本として使用可能
- Mermaid図はすべてGitHub Markdownでのレンダリング互換性を確認済み
- 対話テキストは純粋なテキスト台詞で、Markdown書式を含まないため、音声合成エンジンに直接読み込ませて読み上げるのに適している
