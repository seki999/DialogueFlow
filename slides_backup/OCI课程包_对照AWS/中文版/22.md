# FastConnect vs Direct Connect

一句话说明:通过专线把数据中心接入云端,绕开公网,获得更稳定的带宽和延迟。

```mermaid
flowchart LR
    DC[企业数据中心] -- 专线 --> FC[FastConnect]
    FC --> VCN[VCN]
    VCN --> Cloud[云上资源]
```

## 核心要点
* AWS 对应:Direct Connect
* 用途:企业数据中心与云上VCN之间建立专线连接,替代经由公网的VPN
* 优势:更稳定的带宽、更低延迟、更好的安全性
* 混合云架构中的关键一环,通常和 VCN、路由表配合使用,决定哪些流量走专线、哪些走公网
