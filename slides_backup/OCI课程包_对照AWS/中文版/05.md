# 虚拟机对比:Flex VM vs EC2

一句话说明:OCI 的 Flex VM 让你自己拼装 CPU 和内存比例,而不是选固定实例族。

```mermaid
flowchart TD
    subgraph AWS方式
        E1[选择实例族 m5/c5/r5] --> E2[固定CPU:内存比例]
    end
    subgraph OCI方式
        O1[选择Flex VM] --> O2[自定义OCPU数量]
        O2 --> O3[自定义内存大小]
    end
```

## 核心要点
* AWS EC2:先选实例族(通用型m/计算优化c/内存优化r),比例固定
* OCI Flex VM:先选 Shape(如 VM.Standard.E4.Flex),再自由填写 OCPU 数和内存 GB 数
* 好处:不需要为了多几 GB 内存被迫升级到下一档、多付双倍 CPU 的钱
