# Syslog: Recording Detailed Event Logs

In short: Syslog is responsible for transmitting the detailed operational logs generated inside a device.

```mermaid
flowchart LR
    A[Network Device] -->|UDP or TCP 514| B[Syslog Server]
    B --> C[Log Storage and Analysis]
```

## Key Points

* Common ports are UDP 514, TCP 514, and TLS 6514
* Records interface changes, config changes, login events, system restarts
* UDP is fast to transmit but doesn't guarantee delivery
* TCP or TLS provides higher reliability and security
* Well suited for root cause investigation and auditing
