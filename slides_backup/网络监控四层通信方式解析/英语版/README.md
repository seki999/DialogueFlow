# Course Guide

## Topic

The four communication methods used in network device monitoring: TCP Ping, SNMP GET, SNMP Trap, and Syslog — how they differ, what they're used for, and how they work together.

## Total Chapters

7 file pairs (numbered 01 through 07)

## File Numbering Rules

* Each pair consists of a `.md` file and a `.conversation` file sharing the same number
* Numbers use two digits and are consecutive with no gaps
* Example: `01.md` corresponds to `01.conversation`

## How the Files Correspond

* `.md` files present the chapter's knowledge structure, diagrams, and key points, meant for the on-screen visuals in a recording
* `.conversation` files are a two-speaker script explaining the matching `.md` file, meant for text-to-speech or narration
* The two files correspond strictly; `.conversation` never introduces content that isn't in the matching `.md`

## Recommended Playback Order

Play in numeric order from 01 to 07:

1. 01 - Why We Need Four Monitoring Methods (Background and Problem)
2. 02 - TCP Ping: Checking Port Connectivity
3. 03 - SNMP GET: Actively Querying Device State
4. 04 - SNMP Trap: The Device Reports Problems Proactively
5. 05 - Syslog: Recording Detailed Event Logs
6. 06 - A Combined Scenario: Diagnosing a Router Interface Failure
7. 07 - Summary and Further Thoughts

## How to Use

* When recording or playing a video, display the diagram and key points from each `.md` file in order
* Narrate the matching `.conversation` file's dialogue at the same time (speaker 1 represents the learner's perspective, speaker 2 represents the expert's perspective)
* It's recommended to treat each file pair as an independent video or audio segment
