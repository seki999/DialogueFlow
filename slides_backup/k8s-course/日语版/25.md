# クラスタ管理：DRA でデバイスを割り当てる

一言で言うと：DRA（動的リソース割り当て）は従来のデバイスプラグインより柔軟な方式で、GPU のような特殊なハードウェアを管理するために使われる。

```mermaid
flowchart LR
    Driver[デバイスドライバ] --> DRA[DRA リソース宣言]
    DRA --> Claim[ResourceClaim]
    Claim --> Pod[Pod が特定のデバイスを要求]
    Pod --> Schedule[スケジューラが必要に応じて割り当てる]
```

## 要点

* DRA は GPU などきめ細かい割り当てが必要なハードウェアデバイスを管理するために使われる
* 対応するデバイスドライバをインストールすることでクラスタがこれらのリソースを認識できるようにする
* ResourceClaim は Pod が具体的にどんなデバイスを必要とするかを記述する
* スケジューラは ResourceClaim に基づいて条件を満たすノードを見つける
* 従来のデバイスプラグインよりも複雑な割り当てや共有ポリシーをサポートする
