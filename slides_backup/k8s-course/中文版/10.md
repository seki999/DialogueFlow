# 实战：使用 ConfigMap 配置 Redis

一句话：这个教程把 ConfigMap 用在真实场景里，展示如何用它定制 Redis 的运行参数。

```mermaid
flowchart LR
    A[创建 ConfigMap 保存 redis.conf] --> B[创建 Pod 挂载该 ConfigMap]
    B --> C[Redis 启动时读取自定义配置]
    C --> D[验证配置已生效]
```

## 核心要点

* 先创建包含 redis.conf 内容的 ConfigMap
* Pod 定义中把 ConfigMap 挂载为卷
* Redis 容器启动时指定使用挂载路径下的配置文件
* 可以用 redis-cli 验证配置参数是否生效
* 这是 ConfigMap 从概念到实战的完整闭环
