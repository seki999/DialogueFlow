# 集群管理：使用 DRA 分配设备

一句话：DRA（动态资源分配）是比传统设备插件更灵活的方式，专门用来管理 GPU 这类特殊硬件。

```mermaid
flowchart LR
    Driver[设备驱动] --> DRA[DRA 资源声明]
    DRA --> Claim[ResourceClaim]
    Claim --> Pod[Pod 请求特定设备]
    Pod --> Schedule[调度器按需分配]
```

## 核心要点

* DRA 用于管理 GPU 等需要精细化分配的硬件设备
* 通过安装对应的设备驱动让集群识别这些资源
* ResourceClaim 描述一个 Pod 具体需要什么样的设备
* 调度器根据 ResourceClaim 找到满足条件的节点
* 比传统设备插件支持更复杂的分配和共享策略
