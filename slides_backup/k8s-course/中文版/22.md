# 安全：使用 AppArmor 限制容器对资源的访问

一句话：AppArmor 是 Linux 内核提供的强制访问控制机制，能限制容器只能做被明确允许的事。

```mermaid
flowchart LR
    Profile[AppArmor 配置文件] --> Kernel[Linux 内核强制执行]
    Kernel --> Allow[允许的操作正常执行]
    Kernel --> Deny[被禁止的操作被拦截]
```

## 核心要点

* AppArmor 通过配置文件定义容器允许的行为边界
* 限制范围包括文件访问、网络能力、系统调用等
* 需要先在节点操作系统上加载好对应的配置文件
* Pod 定义中通过注解或字段引用要使用的配置文件
* 即使容器内进程被攻破，也难以突破配置文件设定的边界
