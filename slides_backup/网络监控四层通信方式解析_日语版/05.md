# Syslog：詳細なイベントログを記録する

一言で言うと：Syslogは機器内部で発生した詳細な運用ログの転送を担う。

```mermaid
flowchart LR
    A[ネットワーク機器] -->|UDPまたはTCP 514| B[Syslogサーバー]
    B --> C[ログの保存と分析]
```

## 核心ポイント

* よく使われるポートは UDP 514 TCP 514 TLS 6514
* インターフェースの変化 設定変更 ログイン イベント システム再起動などを記録
* UDPは転送速度が速いが到達を保証しない
* TCPまたはTLSはより高い信頼性とセキュリティを提供する
* 障害の根本原因の調査や監査に適している
