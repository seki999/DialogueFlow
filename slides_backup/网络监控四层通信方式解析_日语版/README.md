# コース説明

## コーステーマ

ネットワーク機器監視の4つの通信方式：TCP Ping、SNMP GET、SNMP Trap、Syslog の違い、用途、および連携方法。

## 総章節数

全7組のファイル（番号 01～07）

## ファイル番号のルール

* 各組は同じ番号の `.md` と `.conversation` の2ファイルで構成される
* 番号は2桁の数字を使用し、連続していて欠番はない
* 例：`01.md` は `01.conversation` に対応する

## ファイルの対応関係

* `.md` ファイル：当該章の知識構造、フロー図、核心ポイントを表示し、動画の画面撮影に使用する
* `.conversation` ファイル：対応する `.md` ファイルの内容を解説する2名の対話原稿で、自動読み上げや録音に使用する
* 両ファイルの内容は厳密に対応しており、`.conversation` に `.md` にない内容は含まれない

## 推奨再生順序

番号順に01から07まで再生する：

1. 01 - なぜ4つの監視方式が必要なのか（背景と課題）
2. 02 - TCP Ping：ポートの疎通確認
3. 03 - SNMP GET：機器の状態を能動的に問い合わせる
4. 04 - SNMP Trap：機器が異常を能動的に通知する
5. 05 - Syslog：詳細なイベントログを記録する
6. 06 - 総合シナリオ：ルーターのインターフェース障害調査
7. 07 - まとめと発展的な考察

## 使用方法

* 動画の再生・録画時は、番号順に各 `.md` ファイルの図とポイントを表示する
* 対応する番号の `.conversation` ファイルの対話内容を同時に読み上げる（speaker 1 は学習者視点、speaker 2 は専門家視点）
* 各組のファイルを独立した動画または音声のセグメントとして扱うことを推奨する
