# 英语单词学习课程包

## 课程说明

本课程面向汉语母语的英语学习者。

每一个英语单词对应两个文件：

- `编号.md`：单词知识卡和图文讲解
- `编号.conversation`：双人问答讲解脚本

## 文件对应关系

| 编号 | 单词 | Markdown 文件 | 对话文件 |
|---|---|---|---|
| 01 | complement | 01.md | 01.conversation |
| 02 | inferiority | 02.md | 02.conversation |
| 03 | persecution | 03.md | 03.conversation |
| 04 | concession | 04.md | 04.conversation |
| 05 | confine | 05.md | 05.conversation |
| 06 | conservative | 06.md | 06.conversation |
| 07 | consignment | 07.md | 07.conversation |
| 08 | contagious | 08.md | 08.conversation |
| 09 | contend | 09.md | 09.conversation |
| 10 | contingent | 10.md | 10.conversation |

## 推荐学习顺序

1. 先打开对应的 `.md` 文件
2. 查看音标、词义、搭配和例句
3. 播放对应的 `.conversation` 文件
4. 跟读对话中的单词、短语和句子
5. 完成快速复习
6. 再进入下一个单词

## 文件命名规则

文件统一使用两位数字编号：

- `01.md`
- `01.conversation`
- `02.md`
- `02.conversation`

以此类推，直到 `10.md` / `10.conversation`。
