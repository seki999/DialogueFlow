# Cluster Management: Allocating Devices with DRA

In short: DRA (Dynamic Resource Allocation) is a more flexible way than traditional device plugins for managing specialized hardware like GPUs.

```mermaid
flowchart LR
    Driver[Device driver] --> DRA[DRA resource declaration]
    DRA --> Claim[ResourceClaim]
    Claim --> Pod[Pod requests a specific device]
    Pod --> Schedule[Scheduler allocates as needed]
```

## Key Points

* DRA is used to manage hardware devices like GPUs that need fine-grained allocation
* Installing the corresponding device driver lets the cluster recognize these resources
* A ResourceClaim describes what kind of device a Pod specifically needs
* The scheduler finds a node satisfying the ResourceClaim's conditions
* Supports more complex allocation and sharing strategies than traditional device plugins
