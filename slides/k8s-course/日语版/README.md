# コース説明

## コースのテーマ

Kubernetes 公式中国語版チュートリアルページ（https://kubernetes.io/zh-cn/docs/tutorials/）に基づいて整理した完全コース：クラスタの基礎、デプロイと設定から、ステートレス/ステートフルアプリの実践、Service の仕組み、セキュリティのハードニング、そしてクラスタ管理の発展的な話題まで。

## 総章数

全26組のファイル（番号 01～26）、「長」バージョンのコースに対応。

## ファイル番号ルール

* 各組は同じ番号の `.md` と `.conversation` の2ファイルを含む
* 番号は2桁の数字を使い、連続して欠番なし
* 例：`01.md` は `01.conversation` に対応

## ファイルの対応関係

* `.md` ファイル：その章の知識構造、フローチャート（Mermaid）、要点を示し、動画画面の収録に使う
* `.conversation` ファイル：対応する `.md` ファイルの内容を解説する二人の対話台本で、自動読み上げや録音に使う
* 二つのファイルの内容は厳密に対応しており、`.conversation` には `.md` にない内容は登場しない

## 推奨再生順序

番号順に 01 から 26 まで再生してください。

## 使い方

* 動画の再生・収録時は、番号順に各 `.md` ファイルの図と要点を表示する
* 対応する番号の `.conversation` ファイルの対話内容を同時に読み上げる（speaker 1 は学習者視点、speaker 2 は専門家視点）
* 各組のファイルを独立した動画または音声のセグメントとして扱うことをお勧めします
