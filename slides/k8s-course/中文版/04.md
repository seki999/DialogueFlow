# 部署应用：使用 kubectl 创建 Deployment

一句话：Deployment 是描述"我要运行什么应用、运行几份"的对象，kubectl 负责把这个愿望变成现实。

```mermaid
flowchart LR
    A[编写/运行 kubectl create deployment] --> B[生成 Deployment 对象]
    B --> C[控制器创建 Pod]
    C --> D[Pod 被调度到节点]
    D --> E[容器实际运行起来]
```

## 核心要点

* Deployment 描述应用的期望状态
* `kubectl create deployment` 是最快创建方式
* Deployment 控制器持续确保实际状态匹配期望状态
* 一个 Deployment 通常对应一个应用组件
* `kubectl get deployments` 查看当前所有 Deployment
