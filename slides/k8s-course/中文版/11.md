# 构造 Pod：使用 Sidecar 容器

一句话：Sidecar 容器和主容器共享同一个 Pod，专门负责日志收集、代理这类辅助工作。

```mermaid
flowchart TB
    Pod[同一个 Pod]
    Pod --> Main[主容器: 业务应用]
    Pod --> Side[Sidecar 容器: 辅助功能]
    Main --> Shared[共享网络/存储]
    Side --> Shared
```

## 核心要点

* Sidecar 与主容器运行在同一个 Pod 里
* 二者共享网络命名空间和可选的存储卷
* 常见用途：日志收集、监控代理、配置同步
* Kubernetes 支持把 Sidecar 声明为特殊类型的 Init 容器
* 主容器专注业务逻辑，辅助功能交给 Sidecar
