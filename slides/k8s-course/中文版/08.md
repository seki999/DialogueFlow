# 更新你的应用：执行滚动更新

一句话：滚动更新逐步替换旧版本 Pod 为新版本，全程保持服务不中断。

```mermaid
flowchart LR
    A[旧版本 3 个 Pod] --> B[逐个替换]
    B --> C[新旧版本短暂并存]
    C --> D[新版本 3 个 Pod]
```

## 核心要点

* `kubectl set image` 触发滚动更新
* 更新过程中新旧版本 Pod 会短暂共存
* 服务在更新期间保持可用，不会整体下线
* `kubectl rollout status` 查看更新进度
* `kubectl rollout undo` 可以回滚到上一个版本
