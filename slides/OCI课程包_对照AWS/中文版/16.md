# File Storage vs EFS

一句话说明:托管的 NFS 文件存储服务,支持多实例共享访问。

```mermaid
flowchart TD
    F[File Storage] --> I1[实例1]
    F --> I2[实例2]
    F --> I3[实例3]
    I1 -.同时读写.- F
    I2 -.同时读写.- F
    I3 -.同时读写.- F
```

## 核心要点
* AWS 对应:EFS
* 基于 NFS 协议,支持多个计算实例同时挂载读写
* 典型场景:多实例共享的应用文件目录、内容管理系统的媒体文件存储
* 和 Block Volumes 的区别:Block Volumes 一般单实例独占,File Storage 天生为多实例共享设计
