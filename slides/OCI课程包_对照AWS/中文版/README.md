# 课程说明:OCI 15个常用服务 对照 AWS 讲解课程

## 课程主题
面向已有 AWS 基础的学习者,系统讲解 Oracle Cloud Infrastructure(OCI)的15个常用服务,
每个知识点均直接对照对应的 AWS 服务进行讲解。

## 总章节数
28 组文件(01 ~ 28),共 56 个文件,外加本 README.md。

## 文件编号规则
- 每个章节包含两个同名文件:`编号.md` 和 `编号.conversation`
- 编号使用两位数字,从 01 开始连续编号,不跳号
- 例如:`01.md` 对应 `01.conversation`,`02.md` 对应 `02.conversation`,以此类推

## .md 与 .conversation 的对应关系
- `.md` 文件:展示当前章节的知识结构、Mermaid 图形和核心要点,用于录制视频时的画面展示
- `.conversation` 文件:以 `speaker 1`(学习者视角)和 `speaker 2`(专家视角)的对话形式,
  逐一讲解对应 `.md` 文件中的图形和要点
- 两个文件内容严格对应,`.conversation` 中出现的所有知识点都能在同编号的 `.md` 中找到出处

## 推荐播放顺序
按编号从 01 到 28 顺序播放/朗读即可,章节之间按照以下逻辑组织:

1. 背景与核心概念(01-03)
2. 计算类:总览 + 7个细分主题(04-12)
3. 存储类:总览 + 4个细分主题(13-17)
4. 网络类:总览 + 4个细分主题(18-22)
5. 数据库类:总览 + 2个细分主题(23-25)
6. 安全类(26)
7. 常见误区与免费套餐(27)
8. 总结与延伸思考(28)

## 使用建议
- 可将每组 `编号.md` 作为录屏画面参考,`编号.conversation` 作为语音朗读/播客脚本使用
- Mermaid 图形均已确认兼容 GitHub Markdown 渲染
- 对话文本为纯文本对白,不含任何 Markdown 格式,适合直接接入语音合成引擎朗读
