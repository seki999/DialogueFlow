# Background and Problem

One-line summary: why is it worth systematically learning OCI even if you already know AWS well?

```mermaid
flowchart LR
    A[Already know AWS] --> B[Encounter an OCI project or migration need]
    B --> C[Different terminology]
    C --> D[No mapping to fall back on]
    D --> E[Low learning efficiency]
    E --> F[This course: build an OCI-AWS mapping]
```

## Key Points
* Target audience: people with an AWS background who want to quickly understand OCI
* Method: skip cloud computing basics, focus only on "what does this OCI service map to in AWS"
* Scope: five categories - compute, storage, networking, database, security - 15 commonly used services total
* Final deliverable: a mapping table you can use directly for reference
