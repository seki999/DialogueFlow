# Block Volumes vs EBS

一言で言うと:コンピュートインスタンスにマウントされるブロックストレージ。オンライン拡張とパフォーマンス階層をサポート。

```mermaid
flowchart LR
    A[コンピュートインスタンス] --> B[Block Volumeをマウント]
    B --> C[オンライン拡張]
    B --> D[パフォーマンス階層選択]
    D --> E[EBS gp3/io2階層に類似]
```

## 要点
* AWS対応:EBS
* オンライン拡張(ダウンタイムなしで容量を調整)をサポート
* パフォーマンス階層はEBSのgp3(汎用型)/ io2(高性能型)と類似のロジック
* 用途:データベースのデータボリューム、永続化が必要なアプリケーションデータディレクトリ
