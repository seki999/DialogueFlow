# FastConnect vs Direct Connect

一言で言うと:専用線でデータセンターをクラウドに接続し、パブリックネットワークを迂回することで、より安定した帯域幅と遅延を得る。

```mermaid
flowchart LR
    DC[企業データセンター] -- 専用線 --> FC[FastConnect]
    FC --> VCN[VCN]
    VCN --> Cloud[クラウド上のリソース]
```

## 要点
* AWS対応:Direct Connect
* 用途:企業データセンターとクラウド上のVCNの間に専用線接続を確立し、パブリックネット経由のVPNを置き換える
* メリット:より安定した帯域幅、より低い遅延、より良いセキュリティ
* ハイブリッドクラウドアーキテクチャの重要な要素。通常VCN、ルートテーブルと組み合わせて使用し、どのトラフィックが専用線を通り、どれがパブリックネットを通るかを決定する
